# 三星战争史与最终反派：新版世界观设定

> 日期：2026-10-13｜项目：《凌晨三点，怪物敲门求救》（书名暂定）｜状态：创作讨论／长篇重构世界观
>
> **版本优先级：**此档记录作者最新确认的背景，覆盖早前「最初只有一颗星球入侵蓝星」「蓝星只是普通程度的军事劣势」等假设。此设定不意味着旧前五章FINAL已经符合新版世界观；保留旧稿作为历史版本。

## 1. 作者明确确定的战争历史

1. **幽墟星与重岳星在战争初期同时攻打蓝星**，两颗异星均为对蓝星的侵略方。这里的「同时攻打」不自动等同已有长期牢固同盟，具体外交关系、共同作战协议尚待补充。
2. 蓝星在「相位泄压场」限制人工高强度瞬时能量输出、削弱枪炮等现代高能武器优势的条件下，整体战力最弱。
3. **蓝星被打残，剩余土地面积不足原先十分之一。** “土地面积”究竟指人类仍控制的领土、剩余宜居土地，还是实际地理空间已经被折叠剥离，**尚需作者澄清**，不能擅自写成整颗地球物理缩小。
4. 后来**幽墟星与重岳星因资源分配发生武装冲突**，两大侵略势力相互交战，蓝星获得喘息和组织反击的机会；地球跨界攻坚军及梁见山所在最精锐队伍，是此背景下的保卫家园力量。
5. 长篇最终大反派是一名**深爱虞静的梁见山旧日同事／战友**，出自蓝星地球攻坚军体系。他后来周旋于幽墟星与重岳星两边，最终**企图毁灭蓝星**。
6. 为避免动机过薄，旧战友如何由深爱虞静、对当年事故不满而走到毁灭蓝星，及是否从开始就怀有此终局，**尚未确定**；不能仅凭「喜欢虞静」推导为「憎恨所有蓝星人」。其具体行动路径、个人能力、是否利用两星资源冲突均待设计。

## 2. 与先前已确认的小说人物及章节结构对接

- **梁见山**：24岁开篇；13岁已进入地球最精锐攻坚军作战体系，18岁有五年经验；20岁／开篇前四年的异星攻坚任务中虞静牺牲，余烬残片进入身体；20至21岁流浪约一年；22岁遇唐栗并合伙开夜宵店，24岁时已合作两年。他是最精锐队伍的武力担当，以超高战斗智商著称，属于全书顶尖战力。
- **虞静**：拥有独立信念，攻坚任务中自愿作出牺牲，真正死亡且不复活；「余烬」非虞静的意识或灵魂，其情感关联须在后期揭示。
- **灰耳**：重岳星狼系兽人，精锐军人／族长，可在狼兽直立本体和地球四足土狗拟态之间变化；两次与梁见山战场交锋（先被梁见山饶命，后因感念救命与反对违背守护族人理念的军令而故意放走地球攻坚小队）。灰耳的儿子如今是重岳星远征军高级将领，由儿子派遣昔日战友追杀灰耳；灰耳仍遵守对妻子保护族人的承诺，活着才可号召族人。昔日战友下死手，他对他们留手；在梁见山与他取胜后，灰耳会阻止处死追兵。
- **唐栗**：房东、夜宵摊出资人与实权经营者，初中毕业、负责本店附近订单配送；两年前因混混收保护费事件结识梁见山；两人因经营权财务决策争吵。旧版寻找弟弟唐野主线**删除**。
- **章节分配（新版六章规划）**：第一、二章铺陈现今社会和战争背景，灰耳本体上门求救、重岳星昔日战友追杀；第三、四章偏无厘头市井日常；第五、六章幽墟星因正面局势受阻而转入渗透蓝星。注意：幽墟星最初对蓝星侵略成功并不与「后期正面受阻」矛盾，但两者**相隔的军事局势变化与渗透目标尚需解释**。
- **相位泄压场**：人工装置驱动的瞬时高能输出受到限制；生物自身代谢和组织运动获得生命相位保护；不能因剧情方便忽略科学设定内部边界。
- **基调**：无厘头、日常群像为主，在真正危机中有清晰的肉搏动作和高智商战斗。千万不要让失去大部分领土的宏大战争背景在普通人食物、水、电、居住、物流与社会秩序层面**完全没有现实后果**。

## 3. 尚待作者决定的关键空白

1. 蓝星「土地不足十分之一」指哪一种：
   - A 仍**由蓝星人类控制的领土**不足原先陆地面积的一成（其余被占领、隔离或处于争议区，物理地表仍在）。
   - B **能实际居住与耕作的地表**不足一成（灾难/空间交叠造成大量区域不再宜居）。
   - C **物理空间发生大规模失去或折叠**，地理意义上的陆地真的减少至不到一成。
   这决定夜宵店所在城市、粮食供应、人口迁徙、军事形势的具体描写。
2. 幽墟星与重岳星争夺的**是什么资源**？由何种机制出现、为何无法和平分配、为什么引发战争？
3. 蓝星如何在严重领土损失后形成**稳定的防御体系、生活供应与夜间商业**？地球人为何仍能生活在夜宵摊附近？
4. 幽墟星从初期优势到**第五、六章采取渗透**的战术转变由什么因素触发？蓝星幸存区、重岳星驻守区分别有哪些正面防御优势？
5. 最大反派深爱虞静，但**为什么将目标设为毁灭蓝星而不是追究当年责任人或推翻旧制度**？他需要具有自洽且足够严重的世界观、个人转折和现实手段，也应承担行动责任。
6. 时间轴：首次小规模空间交叠几十年前、蓝星遭侵略与攻坚军建立、梁见山13岁实战、20岁事故、24岁开篇之间的**具体重大历史阶段**还未标年，不可互相冲突。

## 4. 编辑原则

- 蓝星为**先被侵略的一方**；不因个别人物犯过错就把整个人类整体定性为侵略者。
- 幽墟星与重岳星作为文明包含不同人物和立场；「两星最初进攻」不代表他们各自所有居民均自愿参与战争。
- 最大反派来自蓝星这一设定可形成对照：真正想终结蓝星的人，最终未必是异星生命。这个方向可深化，但暂不替作者确定反派的具体动机和结局。
- 保留历史五章FINAL；新设定下的第一章需新建版本，待作者批准才可称定稿。
